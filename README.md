# Zain Badaruddin Portfolio v2

A custom React + Vite portfolio inspired by the information architecture of modern developer portfolios, but with a distinct editorial dark/light theme and layout.

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Then open the local URL shown by Vite.

## Customize before publishing

Replace the placeholder GitHub, LinkedIn and email links in `src/main.jsx`.

The contact form is intentionally front-end only. Connect it to Formspree, Resend, EmailJS or your own API before production use.
